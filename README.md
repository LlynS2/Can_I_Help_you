    <p align="center">
      Can I help you? was a prototype developed for the Stellantis challenge, which gave us the freedom to apply the SmartCity concept. The idea was created to help people with disabilities and raise awareness and encourage respect for those who are not aware       of the challenges these people face in their daily lives. That's why the application helps both users with disabilities and those who want to volunteer to help these people with whatever they need.
  <p align="left">
      ꒰‧⁺ ✎ A very useful tool that is present in the application is the SOS button, which the user can call the authorities in an emergency situation - for example.
