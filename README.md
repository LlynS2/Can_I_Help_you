    <p align="center">
      Can I Help you? foi um protótipo desenvolvido para o desafio Stellantis, que nos deu a liberdade de aplicar o conceito de SmartCity. A ideia foi criada para ajudar pessoas com deficiências, aumentar a conscientização e incentivar o respeito por aqueles que não conhecem os desafios que essas pessoas enfrentam em suas vidas diárias. É por isso que a aplicação ajuda tanto usuários com deficiências quanto aqueles que querem se voluntariar para ajudar essas pessoas com o que for necessário.
  <p align="left">
      ꒰‧⁺ ✎ Uma ferramenta muito útil presente na aplicação é o botão SOS, que permite ao usuário chamar as autoridades em uma situação de emergência, por exemplo.
